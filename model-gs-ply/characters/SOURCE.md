# Xbot — default sci-fi humanoid

Source: https://github.com/mrdoob/three.js/blob/dev/examples/models/gltf/Xbot.glb
Downloaded 2026-09-30 from the official Three.js examples. Original character/animation source: Adobe Mixamo.
Example: https://threejs.org/examples/webgl_animation_skinning_additive_blending.html

The GLB is preserved unmodified. `src/scifi-character.js` adapts bone names and root motion at load time and adds local jump, hover, flight, driving, wave and careful-walk clips. Material colors match the character-selection preview.
The source model is a third-party asset; the project's own code license does not relicense it.
